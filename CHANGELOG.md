# Changelog

All notable changes to this project are documented in this file.

The format is based on Keep a Changelog and uses semantic versioning.

## [1.1.0] - 2026-08-18

### Changed
- Fixed selection state handling so reopening edit mode keeps the previous selection visible and usable.
- Refined the grid and control layout for a cleaner, more Blizzard-like retail UI.

### Added
- Added localized edit text for the default and German locale files.
- Added a new "Edit" button to toggle marker selection mode
- Kept all marker buttons visible in edit mode and dimmed inactive ones instead of hiding them.
- Updated the addon to use a more reliable zone-based auto-open flow and polished the UI state behavior during playback.

## [1.0.0] - 2026-08-13

### Added
- Initial release of MarkerMemory addon for World of Warcraft.
